# VillaCore Kids
Sitio estático en HTML, CSS y JavaScript, sin dependencias ni servidor. El formulario genera un mensaje de WhatsApp; no registra reservas ni procesa pagos.

## Publicar en GitHub Pages
1. Crear un repositorio público, por ejemplo `VillaCoreKids`.
2. Subir el contenido de esta carpeta (index.html, styles.css, app.js, assets, README.md), no la carpeta contenedora.
3. En Settings > Pages, elegir Deploy from a branch, rama main y carpeta / (root). Guardar.
4. Abrir la URL pública que indica GitHub Pages. Normalmente será https://TU-USUARIO.github.io/VillaCoreKids/.
5. Para una vista previa correcta en Facebook, editar en index.html el meta og:image y cambiar assets/social.jpg por la URL absoluta de esa imagen en tu sitio. Opcionalmente añadir og:url con la URL pública. Verificar la vista previa al compartir.

## Personalizar
- Los precios y textos están en index.html. El número de contacto está en index.html y app.js (50688111444).
- Las imágenes provienen de los anuncios entregados. El logo y las fotos de catálogo son recortes del anuncio, no archivos originales independientes.
- Multicolor y Jurásico son nombres descriptivos propuestos. Verificar nombres, medidas, capacidades, horarios y precios antes de publicar.
- El enlace de Facebook de la empresa no fue proporcionado; el botón comparte la web en Facebook, no enlaza a una página comercial específica.
- No existe un calendario en tiempo real; la disponibilidad debe confirmarse por WhatsApp.
